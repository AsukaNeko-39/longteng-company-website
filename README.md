# 湖南龙腾图跃科技有限公司展示网站

公司展示网站，包含首页、能力与服务、特色地图、案例与合作、认识龙腾五个页面。

采用 HTML、CSS 和 JavaScript，无需安装依赖或运行构建命令。所有网页、样式和图片使用相对路径，支持 GitHub Pages 项目站点部署。

## 浏览方式

网站以逐屏翻页展示五个章节，避免依赖长页面滚动。首页固定为五个主要展示页：公司概览、技术服务、农耕文化与湘超双地图、行业案例、公司团队与产学研合作；业务咨询作为附加页，不计入五页编号。其余章节按窗口尺寸适配内容。

- 点击底部上一页、下一页按钮，或用方向键、Page Up / Page Down、鼠标滚轮翻页。
- 手机可左右滑动翻页，也可点击底部箭头。
- 点击“目录”可直接切换内容；顶部导航用于切换章节。
- 首页的农耕文化地图与湘超数字地图以重叠相片展示，点击相片切换前景和对应介绍，也可用左右方向键切换。
- 图片支持放大预览，专题页保留标签切换；减少动态效果的系统设置会关闭过渡动画。

## 页面

- `index.html`：公司概览、空间数据服务及重点项目。
- `services.html`：地理空间数据、GIS二三维一体化、物联网与遥感应用。
- `maps.html`：湖南省农耕文化地图、湘超数字地图。
- `cases.html`：行业案例与合作交流。
- `about.html`：公司、团队、技术方向与联系方式。

## 发布与更新

GitHub Pages 使用 `main` 分支的根目录发布。提交网页文件到 `main` 后，GitHub 自动更新网站。`.nojekyll` 用于按静态文件发布。

本地预览可在仓库目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。

公司及业务信息依据企业提供的介绍材料整理。项目界面来自相关用户手册，合作交流照片由企业提供，案例图示的资料来源已在页面标注。
